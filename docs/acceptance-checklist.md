# Приемане

Проверено локално на 9 октомври 2026.

| Критерий | Резултат |
| --- | --- |
| GeneratePress не е променяна | Да. Инсталирана е 3.6.1 от официалния пакет. |
| Child theme и MyTaxi Core се активират | Да. |
| Услугите и маршрутите се редактират от админа | Да. Екраните и полетата са налични. |
| Съдържанието е в плъгина, не в темата | Да. Типовете и meta са в MyTaxi Core. |
| Договорените адреси се отварят | Да. Всички върнаха HTTP 200. |
| Няма slug конфликт в началните записи | Да. Проверката хваща зает адрес. |
| Контактите идват от услугата | Да. Taxi Albena показва +359896817384. |
| Маршрутът наследява контакта | Да. Varna Airport → Albena показва +359888850884. |
| Цената има един източник | Да. Смяната в записа сменя етикета. |
| Липсваща цена не е 0 € | Да. Текстът е Price on request и няма Offer цена. |
| Получателят се определя на сървъра | Да. |
| Без получател няма фалшив успех | Да. Страницата го казва и проверката го потвърждава. |
| Успехът не е потвърдена резервация | Да. Текстът казва, че екипът още трябва да потвърди. |
| Мобилно без overflow и без покрити полета при фокус | Да за Taxi Albena на 390 px. Менюто се отваря. |
| Основното съдържание е в HTML | Да. |
| Няма двоен canonical или двоен schema блок | Да. По един от всеки. |
| Няма фалшиви отзиви и непотвърдени твърдения | Да. Банерът за примерно съдържание е видим. |
| Пренасочванията на новия сайт нямат цикъл | Да. `/balchik` остава 404. |
| Инструкция за клиента | Да. `docs/admin-guide.md`. |

Не е правено: публикуване, Search Console, реално отваряне на старите домейни в тази сесия и потвърждение, че продукционната поща доставя писмо. Локалният Mailpit получи тестово писмо. Това не доказва доставка при клиента.
